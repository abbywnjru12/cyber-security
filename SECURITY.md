# Security Policy

## Responsible use
This repository is intended for defensive education and authorized log analysis only. Do not use it to access systems or data without permission.

## Data handling
- Do not commit real authentication logs to a public repository.
- Remove usernames, hostnames, IP addresses, tokens, and other identifying details before sharing examples.
- The included sample log uses documentation-only IP address ranges.

## Reporting an issue
For a project issue, open a GitHub issue with a clear description and a safe, sanitized example. Do not publish sensitive logs or credentials.
